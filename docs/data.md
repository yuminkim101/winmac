# 데이터 및 정확성 원칙

## 공통 항목에 필요한 정보(초안)
- ID, 항목 유형(command/shortcut), 작업 목적, 검색 동의어
- Windows 환경 및 표현, Mac 환경 및 표현
- 쉬운 한국어 설명, 차이 유형(명령어/문법/동일/환경 의존)
- 카테고리, 추천 학습 순서, 관련 항목
- 검증 출처/일자, 적용 환경, 주의사항
- 필요 시 '오류 원인 추정' 문구 및 추정 근거

## 검증 사례
- CMD `dir` ↔ zsh `ls` (목록 확인의 기본 예시)
- CMD `cd..` ↔ zsh `cd ..` (공백 문법 차이)
- `mkdir` (양쪽에서 사용 가능; 옵션/세부 동작은 다를 수 있음)

## 원칙
- 단순 문자열 치환으로 모든 명령어를 변환하지 않는다.
- VS Code 단축키는 앱/OS/키맵 설정을 확인한다.
- 사용자 환경 및 실제 오류를 모를 때는 '오류 원인 추정'이라고 표기한다.
- 데이터 30~50개는 검토 중인 초기 규모 가설이다.
