# MVP 기능 범위

## 합의된 서비스 구성
- SEARCH: CMD↔zsh 명령어, Windows↔Mac VS Code 단축키를 빠르게 찾기
- EXPLORE: 카테고리별 전체 항목 탐색
- LEARN: 입문자 추천 학습 순서
- 세 방식은 공통 항목 데이터를 재사용

## 우선 검토 기능
대응 명령어/단축키, 쉬운 의미 설명, 차이점, 오류 원인 추정, 복사, 카테고리 분류, 학습 순서.

## 상세 결정 대기
행동 중심 검색, 역방향 검색의 구체 동작, 동의어·연관 항목, 초기 데이터 수량, 학습 화면 깊이.

## 출시 후 후보
즐겨찾기, 최근 본 항목, 진도 기록, 퀴즈, AI 기반 오류 메시지 분석. 사용자 가치 검증 전 추가하지 않는다.
