# 사용자 검증 및 성과 지표

## 검증 가설
H1. Windows 기준 수업의 Mac 사용자에게 환경 차이로 인한 실습 중단이 반복된다.
H2. 입문자는 오류 메시지나 적절한 검색어를 이해하기 어렵다.
H3. 검색 외 카테고리 사전/추천 학습 순서가 추가적인 이용 가치를 제공한다.
H4. 기존 검색·ChatGPT 대비 전용 서비스가 더 빠르고 이해하기 쉽다.

## 지표 후보
- 검색 성공률, 실제 문제 해결률
- 검색 후 사전 이동률, 학습 연속 열람률
- 재사용 의향, 기간별 재방문율

## 주의
지표의 계산 방식·목표치·수집 방법은 미확정. 재방문율이 낮아도 학습 완료 때문일 수 있으므로 단독으로 성공/실패를 판단하지 않는다.
