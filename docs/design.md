# 디자인 및 인터랙션 방향

상태: 방향성만 합의, 구체적인 화면/스타일 미확정.

## 레퍼런스
- https://www.noth.in/?ref=siteinspire
- https://www.siteinspire.com/website/2969-david-mcgillivray

## 합의된 취향
- 시각적 스타일과 인터랙션 모두 중요
- 현대적이고 세련된 에디토리얼/타이포그래피 중심 접근 검토
- 획일적인 AI 생성 SaaS 템플릿 느낌을 피할 것

## 지양
- 반복적인 둥근 카드, 의미 없는 그라데이션, 불필요한 아이콘/배지, 획일적 호버 효과

## 검토할 인터랙션
- 검색 반응과 결과 전환
- 목록 탐색 및 상세 확장
- 복사 성공 피드백
- 텍스트 중심의 정교한 호버/모션

## 필수 원칙
- 수업 중 빠르게 찾고 복사할 수 있는 사용성을 우선
- 모바일·키보드 접근성, 모션 감소 설정 고려
- 레퍼런스의 화면을 그대로 복제하지 않음
- 색상/폰트/애니메이션 스펙/와이어프레임은 미확정
