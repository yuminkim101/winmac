# 문제 정의

## 실제 경험
- 강사 환경: Windows CMD, 사용자 환경: macOS zsh (VS Code 터미널 또는 cmux).
- CMD에서 안내된 `cd..`을 zsh에 입력해 오류 발생.
- 오류 원인을 이해하지 못해 ChatGPT에 질문.
- 수업 중 같은 질문을 하는 사람이 많았음(비공식 관찰).
- 다른 경험: `dir`/`ls`, `mkdir`, `pwd`, `code .`, npm 설치, PATH, 셸 차이, VS Code 줄 복사 단축키.

## 문제 가설
Windows 기준 실습을 Mac으로 따라가는 입문자는 명령어·문법·단축키 차이로 막히고, 검색 키워드와 오류 원인을 스스로 판단하기 어려워 학습 흐름이 끊긴다.

## 검증 필요
문제 발생 빈도, 해결까지 걸리는 시간, 기존 검색/AI 대비 전용 서비스의 이점. 수업 중 같은 질문이 많았다는 것은 비공식 관찰이므로, 수업 밖 전체 사용자 사실로 일반화하지 않는다.
