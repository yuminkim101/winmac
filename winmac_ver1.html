CMD ↔ zsh 길잡이

Windows CMD로 배운 명령어와 VS Code 단축키를 Mac에서는 어떻게 쓰는지, 왜 다른지까지 쉽게 알려 드려요.

/ 키를 누르면 검색창으로 이동해요. CMD 명령어도, zsh 명령어도 검색돼요.

36개 결과

문법만 달라요

macOS zsh

폴더 안에 어떤 파일과 폴더가 있는지 보여 주는 명령이에요. 이름만 다르고 하는 일은 같아요.

검증 상태: 초안 (공식 문서 확인 전)

숨김 파일까지 목록 보기

문법만 달라요
Windows CMD
dir /a
macOS zsh
ls -a

zsh의 옵션은 '/a'가 아니라 '-a'처럼 하이픈(-)으로 써요. Mac에서 이름이 점(.)으로 시작하는 파일이 숨김 파일이에요.

상위 폴더로 이동

문법만 달라요
Windows CMD
cd..
macOS zsh
cd ..

zsh에서는 명령어(cd)와 대상(..) 사이에 공백이 필요해요. CMD에서는 붙여 써도 동작하는 특별한 경우라서 수업 안내를 그대로 따라 하면 막힐 수 있어요.

오류 원인 추정: 'cd..'를 zsh가 하나의 낯선 명령어 이름으로 읽었을 가능성이 커요. 실제 오류 메시지는 확인하지 못했어요.

검증 상태: 초안 (공식 문서 확인 전)

홈 폴더로 이동

문법만 달라요
Windows CMD
cd %USERPROFILE%
macOS zsh
cd ~

'~'(물결표)는 내 홈 폴더를 뜻해요. 그냥 cd만 입력해도 홈으로 가요. Windows 환경변수는 %이름%, zsh는 $이름 형태예요.

다른 드라이브로 이동

동작이 달라요

(해당 없음)

Mac에는 C:, D: 같은 드라이브 문자가 없어요. 모든 것이 하나의 폴더 트리(/)에 있고, 외장 디스크는 보통 /Volumes 아래에 보여요.

동작이 달라요
Windows CMD

CMD는 cd만 입력해도 현재 위치를 보여 주지만, zsh의 cd만 입력하면 '홈으로 이동'해요! 현재 위치를 보려면 pwd를 쓰세요.

주의 같은 글자(cd)가 환경마다 다르게 동작하니 주의하세요.
